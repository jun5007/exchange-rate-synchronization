# 입력 데이터 계약

공개 R 스크립트에는 다음 로컬 파일이 필요합니다.

```text
data/merged_50stocks_fx_multi.csv
```

이 계약은 별도로 공개된 R 구현에만 적용되며, 학술대회 논문과 연결된 전체 연구 파이프라인을 설명하거나 재현하지 않습니다.

원본 시장·환율·외국인 보유 자료는 포함하지 않습니다. 출처별 재배포 조건과 팀의 공개 동의를 확인하기 전에는 원본 또는 파생 데이터셋을 공개하지 마세요.

## 출처 확인 상태

예상 입력은 종목 수익률, USD/KRW 수익률, 외국인 지분율 변화를 결합합니다. 구체적인 데이터 제공처, 추출 항목, 수집일, 라이선스는 공개 저장소에 남아 있지 않습니다. 대체 입력 파일을 준비하거나 공개하기 전에 원본 팀 자료에서 이를 확인해야 합니다.

## 필수 컬럼

| 컬럼 | R 자료형 | 필수 형식 | 의미 |
|---|---|---|---|
| `종목` | character | 스크립트의 `sector_map`과 일치하는 비어 있지 않은 종목명 | 종목 식별자 |
| `일자` | Date | ISO `YYYY-MM-DD` | 거래일 |
| `ret` | double | 유한한 숫자 | 공개 구현에서 사용하는 종목 수익률 |
| `fore_chg` | double | 유한한 숫자 | 외국인 보유 비율 변화 |
| `USD_ret` | double | 유한한 숫자 | USD/KRW 수익률 |

추가 컬럼이 있어도 되며 자료형은 읽는 과정에서 추론합니다. 필수값이 없거나 숫자가 유한하지 않은 행, 고정 `sector_map`에 없는 종목은 스크립트에서 제외합니다.

한 행의 기준은 한 거래일의 한 종목(`종목` × `일자`)입니다. 현재 스크립트는 중복 키를 거부하지 않으므로 실행 전 중복을 확인해야 하며, 중복 행은 월평균을 바꿀 수 있습니다.

결과를 해석하기 전에 `ret`, `fore_chg`, `USD_ret`의 단위와 산출 방식을 확인해야 합니다. 특히 일별 산술 수익률과 퍼센트포인트 값을 같은 단위로 취급해서는 안 됩니다.

## 설명용 합성 예시

다음 행은 스키마만 보여 주는 합성 예시이며 원본 프로젝트 데이터가 아닙니다.

```csv
종목,일자,ret,fore_chg,USD_ret
삼성전자,2024-01-02,0.0012,0.0003,-0.0008
삼성전자,2024-01-03,-0.0006,-0.0001,0.0005
SK하이닉스,2024-01-02,0.0018,0.0002,-0.0008
```
